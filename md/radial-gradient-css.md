It can be **circular** or **elliptical**, and you can control its size, position, and color stops.# Basic Syntax```lang-cssbackground: radial-gradient(shape size at position, color-stop1, color-stop2, ...);```**shape**: circle | ellipse (default is ellipse)**size**: closest-side, closest-corner, farthest-side, farthest-corner (default is farthest-corner)**position**: center (default) or any position like top left, 50% 50%**color-stop**: A color with optional stop position (px, %)# Examples1. Simple Circular Gradient```lang-cssdiv {  width: 300px;  height: 300px;  background: radial-gradient(circle, red, yellow, green);}```>>>> Creates a circular gradient from red in the center to green at the edges.>>>> Creates a circular gradient from red in the center to green at the edges.2. Elliptical Gradient with Position```lang-cssdiv {  width: 300px;  height: 200px;  background: radial-gradient(ellipse at top left, #ff0000, #0000ff);}```> Elliptical gradient starting from the top-left corner.3. Gradient with Specific Color Stops```lang-cssdiv {  width: 300px;  height: 300px;  background: radial-gradient(circle, red 20%, yellow 40%, green 80%);}```>Colors change at 20%, 40%, and 80% of the radius.4. Fixed Size Gradient```lang-cssdiv {  width: 300px;  height: 300px;  background: radial-gradient(circle closest-side, pink, purple);}```>Gradient ends at the closest side of the box.✅ Tip: You can combine `radial-gradient()` with `linear-gradient()` or multiple backgrounds for complex effects.If you want, I can give you a CSS demo with multiple radial gradients to create effects like spotlights or bubbles.Do you want me to prepare that?
