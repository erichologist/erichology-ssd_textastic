The font-variant property is used for "small caps" or "titling caps", which are capital letters in a smaller font size than normal uppercase letters. ### CSS Properties for Capitalization| Property  | Value              | Effect          || :-------- | :----------------  | :-------------- || `text-transform` | `uppercase` ||| Converts all letters to full-size capitals. The standard way to force text to be all caps in CSS |||| `font-variant-caps` | `small-caps` ||| Displays lowercase letters as uppercase letters, but at a reduced size (typically the size of the original lowercase letters). This is often used for acronyms or short headlines in professional typography. |||| `font-variant-caps` | `all-small-caps` ||| Forces both original uppercase and lowercase letters to appear as small capitals. |||| `font-variant-caps` | `titling-caps` ||| Uses capital letter glyphs specifically designed for use in all-caps sequences, which often appear less heavy than standard capitals.  ||||         |       |  Property        | Value      || :------ | :---- | ---------------: | :---------- ||         |       | `text-transform` | `uppercase` ||  effect: | Converts all letters to full-size capitals.
