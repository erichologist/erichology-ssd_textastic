To enable *common* and *contextual ligatures*, use the `common-ligatures` value: ```lang-css.element {	font-variant-ligatures:	 common-ligatures; }```To also include `discretionary ligatures`, which are often *stylistic* and *font-specific*, add `discretionary-ligatures`: ```lang-css.element {	font-variant-ligatures: 		common-ligatures discretionary-ligatures;}```#### **Using font-feature-settings**: ##### *(lower-level)*> For more granular control or when specific OpenType features not covered by `font-variant-ligatures` are needed, `font-feature-settings` can be used. To enable *common* and *contextual ligatures*, use the `liga` and `clig` tags: ```lang-css.element {  font-feature-settings: 	  "liga" 1, "clig" 1;}```To also include `discretionary ligatures`, add the `dlig` tag: ```lang-css.element {  font-feature-settings:	  "liga" 1, "clig" 1, "dlig" 1;}```##### *Important Notes*:- **Font Support**: The chosen font must support the specific OpenType ligature features for these CSS properties to have any effect.- **Browser Compatibility**: While font-variant-ligatures is widely supported, font-feature-settings may require vendor prefixes for older browsers.- **Default Behavior**: Some fonts and browsers may enable common ligatures by default.- **Performance**: Activating many OpenType features can sometimes impact rendering performance, especially with complex fonts or large amounts of text.|----|----|----|| **Font Support**: |||| |The chosen font must support the specific OpenType ligature features for these CSS properties to have any effect.||| **Browser Compatibility**	 :|||| |While font-variant-ligatures is widely supported, font-feature-settings may require vendor prefixes for older browsers.||| **Default Behavior**: |||| |Some fonts and browsers may enable common ligatures by default.||| **Performance**: |||| |Activating many OpenType features can sometimes impact rendering performance, especially with complex fonts or large amounts of text.||
