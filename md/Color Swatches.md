[^1][^2][^3][^4]1. Using the HTML Color Picker Input (`<input type="color">`) [^5]The easiest way to create a functional color swatch that opens a native color picker is using the `<input type="color">` element. This approach is simple and widely supported in modern browsers. [^5][^6][^7][^8][^9]HTML:```lang-html<label for="colorPicker">Select Color:</label><input type="color" id="colorPicker" value="#ff0000">```<label for="colorPicker" style="margin:0 .25rem;">Select Color:</label><input type="color" id="colorPicker" value="#DD0A8A" style="margin:0 .25rem;">- The `type="color"` attribute renders a small color swatch on the page.- The `value` attribute sets the initial color, which must be a seven-character hexadecimal notation (e.g., `#ff0000` for red). If no value is specified, it defaults to black (`#000000`). [^5][^10][^11][^12]        You can track changes to the selected color using JavaScript event listeners. [^13]2. Creating a Custom Color Swatch with HTML and CSSFor more control over the appearance and functionality (e.g., displaying specific colors as part of a product list), you can use HTML and CSS to build custom elements. [^14][^15][^16][^17]_HTML_:```lang-html<div class="color-swatch-container">	<div class="color-swatch" style="background-color: #3498db;"></div>	<span class="color-code">#3498db</span></div><div class="color-swatch-container">	<div class="color-swatch" style="background-color: rgb(46, 204, 113);"></div>	<span class="color-code">rgb(46, 204, 113)</span></div>```<div class="color-swatch-container">	<div class="color-swatch" style="background-color: #3498db;"></div>	<span class="color-code">#3498db</span></div><div class="color-swatch-container">	<div class="color-swatch" style="background-color: rgb(46, 204, 113);"></div>	<span class="color-code">rgb(46, 204, 113)</span></div>_CSS_:```lang-css.color-swatch-container {  display: flex;  align-items: center;  margin-bottom: 10px;}.color-swatch {  width: 40px;  height: 40px;/*  border: 1px solid #ccc;*/  border-radius: 5px;	box-shadow:	 inset rgba(5,5,5,.34) 0 0 10px,	 #0002 0 0 10px;	 /* Optional: for a	  softer look */		  margin-right: 10px;  cursor: pointer;	 /* Indicates it might	  be interactive */}.color-code {  font-family: monospace;  color: #555;}```This method uses `div` elements and applies the desired color using the `background-color` CSS property, accepting various color values like HEX, RGB, or HSL.
