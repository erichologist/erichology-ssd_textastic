[^1][^2][^3][^4]### 1. Using the HTML Color Picker Input (`<input type="color">`) [^5]The easiest way to create a functional color swatch that opens a native color picker is using the `<input type="color">` element. This approach is simple and widely supported in modern browsers. [^5][^6][^7][^8][^9]HTML:```lang-html<label for="colorPicker">Select Color:</label><input type="color" id="colorPicker" value="#ff0000"><!--<label for="colorPicker" style="margin:0 .25rem;">Select Color:</label><input type="color" id="colorPicker" value="#DD0A8A" style="margin:0 .25rem;">-->```- The `type="color"` attribute renders a small color swatch on the page.- The `value` attribute sets the initial color, which must be a seven-character hexadecimal notation (e.g., `#ff0000` for red). If no value is specified, it defaults to black (`#000000`). [^5][^10][^11][^12]        You can track changes to the selected color using JavaScript event listeners. [^13]2. Creating a Custom Color Swatch with HTML and CSSFor more control over the appearance and functionality (e.g., displaying specific colors as part of a product list), you can use HTML and CSS to build custom elements.
