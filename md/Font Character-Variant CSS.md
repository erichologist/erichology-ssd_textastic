[^1][^2]These features are typically used to access alternative glyphs for individual characters, such as:  - `cv02`: An open or alternative "4". - `cv06`: A simplified "u" (often a non-descending 'u' or similar variant). [^1][^2]How to Use `cv02` and `cv06` in CSS [^1][^2]You can enable these features using one of two CSS properties: [^4]   1. Using [`font-feature-settings`](#font-feature-settings)   2. Using `font-variant-alternates`&nbsp;<ul>	<li><code>cv02</code>: An open or alternative "4".</li>	<li><code>cv06</code>: A simplified "u" (often a non-descending 'u' or similar variant).</li></ul>[[#font-feature-settings]]# Section One## Subsection 1.1* [Section One](#section-one)  * [Subsection 1.1](#subsection-11)* [Section Two](#section-two)# Section Two1. Using `font-feature-settings` (Wider but older support)  - This property directly accesses raw OpenType feature tags. The value is a comma-separated string of feature tags. [^2][^5][^6][^7]```lang-css.use-variants {  /* enables cv02	   and cv06 features */  font-feature-settings:	  "cv02" on, "cv06" on;  /* Vendor prefixes may be	 needed for older browsers */  -webkit-font-feature-settings:	  "cv02" on, "cv06" on;  -moz-font-feature-settings:	  "cv02" on, "cv06" on;}```2. Using `font-variant-alternates` (Modern CSS, but less universal support) This is the newer, more semantic approach. You can use the `character-variant()` functional notation. [^2][^8][^9][^10][^11]```lang-css.use-variants-modern {  /* Enables cv02 and	 cv06 features */  font-variant-alternates: 	 character-variant(cv02), 	 character-variant(cv06);}```3. Using `@font-feature-values`For the modern syntax, it is recommended to map human-readable names to the OpenType tags within an `@font-feature-values` at-rule. This makes the CSS more maintainable. [^2][^12][^13][^14]```lang-css@font-feature-values "Your Font Name" {  @character-variant {    alt-four: 2;	/* Maps "alt-four" 	to cv02=1 	(or specific value 	depending on font) */    simple-u: 6;	/* Maps "simple-u" 	to cv06=1 */  }}.use-variants-mapped {  font-family: "Your Font Name";  font-variant-alternates: 	 character-variant(alt-four), 	 character-variant(simple-u);}```>*Note*: The exact appearance of the glyphs depends entirely on whether the specific font file (e.g., the Inter font family, which supports these variants) has been designed with those alternative glyphs included.
