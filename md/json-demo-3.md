[^1][^2]Example Nested JSON (3 Levels Deep)The following example demonstrates a 3-level deep JSON structure, which you can use as a test file:```lang-json{  "store_info": {    "store_id": "ST101",    "location": "New York",    "products": [      {        "product_id": "P501",        "name": "Laptop",        "details": {          "brand": "TechCorp",          "price": 1200.00,          "in_stock": true        }      },      {        "product_id": "P502",        "name": "Mouse",        "details": {          "brand": "AccessoryPro",          "price": 25.50,          "in_stock": false        }      }    ]  },  "last_updated": "2025-01-13T12:00:00Z"}```• Level 1: The root object  contains  and .• Level 2: The  object contains the  array .• Level 3: Each item within the  array is an object that contains a nested  object .Key Syntax Rules for Nested JSON• Objects are enclosed in curly braces  and contain key-value pairs. Keys must be double-quoted strings, followed by a colon, then the value.• Arrays are enclosed in square brackets  and contain an ordered collection of values (which can be strings, numbers, objects, or other arrays).• Nesting occurs when the value of a key is another object or an array.• Commas separate multiple key-value pairs within an object and multiple items within an array.• You can use online tools like  JSONLint or  JSON Editor Online to validate your test file's syntax.[^1]:https://docs.lokalise.com/en/articles/1400773-json-nested-json[^2]:https://www.digitalocean.com/community/tutorials/an-introduction-to-json[^3]:https://stackoverflow.com/questions/5176433/how-do-i-properly-structure-nested-json-values[^4]:https://stackoverflow.com/questions/31384651/how-to-identify-if-a-json-object-is-nested-or-not[^5]:https://www.youtube.com/watch?v=G26X4vydj5k[^6]:https://stackoverflow.com/questions/11045639/difference-between-and-when-formatting-json-object[^7]:https://jsoneditoronline.org/indepth/datasets/json-file-example/
