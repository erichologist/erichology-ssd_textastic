[^1][^2]Here are the methods to insert a YouTube video into Markdown: ## Method 1: HTML Iframe (Best for Websites/CMS) [^1][^3]If your Markdown processor supports HTML (like in GitHub Pages, Jekyll, or Obsidian), you can use an `<iframe>` tag: [^1][^4][^5]```lang-html<iframe   width="560"   height="315"   src="https://www.youtube.com"   frameborder="0"   allowfullscreen></iframe>```Replace `VIDEO_ID` with the actual ID from your YouTube URL (e.g., for `://youtube.com`, the ID is `12345`). [^6][^7]## Method 2: Clickable Thumbnail Image (Best for GitHub README) [^8][^9][^10][^11][^12]GitHub does not allow `<iframe>` tags in README files for security reasons. The best way to "embed" a video in GitHub is to use a linked image (thumbnail): ```lang-markdown[![Alt text](https://img.youtube.com/vi/VIDEO_ID/0.jpg)](https://www.youtube.com)```### How to get the thumbnail image:- __High Quality__: `https://img.youtube.com/vi/VIDEO_ID/hqdefault.jpg`- __Max Quality__: `https://img.youtube.com/vi/VIDEO_ID/maxresdefault.jpg`- __Standard__: `https://img.youtube.com/vi/VIDEO_ID/0.jpg` [^13][^14][^15]## Method 3: Simple LinkIf you don't need a player or thumbnail, a simple hyperlink works in all Markdown viewers: [^16]```lang-markdown[Watch Video](https://www.youtube.com)```# ___Tips___- _Obtaining the ID_: The YouTube video ID is the string of characters after `v=` in the URL (e.g., in `https://www.youtube.com/watch?v=dQw4w9WgXcQ`, the ID is `dQw4w9WgXcQ`).- _Embedding in GitHub_: You can also simply copy and paste a YouTube URL into GitHub issues or PRs, and it will often automatically generate a link preview.- _Obsidian_: In Obsidian, you can use the syntax ![youtube](https://www.youtube.com... ) to embed the player directly.
