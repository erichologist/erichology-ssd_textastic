This style relies on volume, refraction, and blur to create the illusion of a physical object (like a glass rod, a mercury spill, or a holographic wire).Since standard border-bottom properties cannot support blurs or complex layers, the best approach is to use a pseudo-element (::after) on your <h1> or a styled <hr>. This allows you to add height, background blurs, and gradients independently of the text. ### 1. **Style 1**: The Mercury Line (Chrome)>This style mimics molten metal. It relies on a "hard" gradient with sudden color stops to create the illusion of a reflective surface. It works best with a very thin height (2-4px) to look like a wire. ```lang-cssh1 {  position: relative;  margin-bottom: 1.5rem;}h1::after {  content: "";  position: absolute;  left: 0;  bottom: -10px;  height: 3px;  width: 100%;    /* The Chrome Gradient:	 Sharp transitions create the shine */  background: linear-gradient(    90deg,    #silver 0%,    #ffffff 40%,    #silver 50%,    #999999 55%,    #silver 100%  );    /* Optional:	 Rounded ends for a liquid feel */  border-radius: 2px;}```### 2. **Style 2**: The Holo-Drip (Iridescent)>>This variation mimics spilled oil or holographic fluid.
