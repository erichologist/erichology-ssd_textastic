[^1][^2][^3]## Textastic and MultiMarkdownTextastic, a text and code editor for iPhone and iPad, has built-in support for MultiMarkdown, which is an extension of standard Markdown. This support includes MultiMarkdown tables, a feature that provides advanced table functionalities such as: - Cell spans over columns and rows.- Multiple table headers.- Table captions. [^3]Previously, Textastic used a different library that only supported basic "PHP Markdown extra" table syntax, but a 2019 update to version 9.8.7 integrated MultiMarkdown 6 support. ## `markdown-it-multimd-table` [^3]The `markdown-it-multimd-table` library is a plugin for the popular JavaScript Markdown parser markdown-it. Standard Markdown specifications only define basic tables, often requiring raw HTML for advanced features like spanned cells. This plugin extends markdown-it to recognize the robust MultiMarkdown table syntax, offering features such as: - Cell spanning across columns and rows.- The ability to divide rows into sections.- Support for block-level elements within cells.- Table captions. [^3]## Summary of Differences| Feature | Textastic <sup>App</sup> | `markdown-it-multimd-table` <sup>JS Plugin</sup>   || ------- | -------------- | ---------------------------------------- || Type    | An iOS/iPadOS code editor application. | A JavaScript library plugin for the markdown-it parser. || Purpose | To edit, view, and preview files on Apple devices. | To extend the markdown-it parser with advanced table functionality for web/app development. || Integration    | Built-in native support for MultiMarkdown syntax.  | Requires manual implementation in a JavaScript project to function. || Functionality  | Provides a user interface for editing and viewing MultiMarkdown. | Parses MultiMarkdown table syntax into HTML output in a programming environment. |[^2][^3][^5][^9][^10][^11]### `markdown-it-multimd-table` | NPM### Aug 12, 2023 | Intro.Markdown specs defines only the basics for tables.
