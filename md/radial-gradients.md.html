The CSS `radial-gradient()` function is used with properties like `background` or `background-image` to create a color transition that radiates from a central point, forming either a circle or an ellipse. It is a powerful tool for creating smooth, dynamic background effects. [^1][^2][^3][^4][^5]



myhd0a

Syntax

The basic syntax for a `radial-gradient` is: 

.rd {
  background: radial-gradient(
	  shape size at position,
	  color-stop1,
	  color-stop2,
	 ...);
	 margin-right: auto !important; margin-left: auto !important;
}
Most parameters are optional, with the only required inputs being at least two color stops. [^6]

Key Components

- ``: Can be circle or `ellipse`. The default is `ellipse`. - ``: Defines the size of the gradient's ending shape. The default is `farthest-corner`. Other keywords include `closest-side`, `farthest-side`, and `closest-corner`. - ``: Sets the center point of the gradient. By default, it's `center`. You can use keywords (`top`, `right`, `bottom`, `left`) or length/percentage values (e.g., at `70% 30%`). - : A list of colors and their positions along the gradient ray (e.g., `red 0%`, `blue 50%`, `black 100%`). The colors are smoothly transitioned between the defined stops. [^1][^2][^6][^7][^8][^9][^10][^11]

Basic Example

A simple radial gradient from red to yellow to green, centered by default: [^12][^13] 

.myDiv {
  background-image: radial-gradient(
	  red, yellow, green);

}

Advanced Examples

- A`circle` positioned at the top left corner: 

.myDiv {
	background-image: radial-gradient(
	  circle at top left,
		red, yellow);
}


.myDiv {
  background-image:
	 radial-gradient(
	  circle at top left,
		red, yellow);
}
< - An `ellipse` with defined size and specific color stop percentages: 

.myDiv {
  background-image:
	 radial-gradient(
	  ellipse farthest-corner,
	  red 0%, blue 50%, black 100%);

}
- A repeating radial gradient: This function behaves similarly to `radial-gradient()` but repeats the pattern infinitely to cover the element. [^6][^14][^15][^16][^17] 

.myDiv {
  background-image:
	 repeating-radial-gradient(
	   red, 
		 yellow 10%, 
		 green 15%);
}

To prevent a `radial-gradient` from repeating behind an image in CSS, you need to use the `background-repeat` property and set its value to no-repeat for the gradient layer. [^21][^22]

Gradients in CSS are treated as images, and by default, background images repeat both horizontally and vertically to fill their container. [^23][^24][^25]

Solution using multiple backgrounds

The best approach is to apply multiple backgrounds to the same element:

one for the image and one for the gradient. This allows you to control the repeat behavior of each layer individually. 2627282930 

.my-container {
  /* Multiple backgrounds on 
	the same element */
  background-image:url('your-image.png'), 
    radial-gradient(circle, 
		#ff8a00, #e52e71);

  /* Prevent the image from repeating, 
	but allow the gradient to cover 
	the whole area */
  background-repeat: no-repeat, repeat; 
	
  /* Optional: Center the image
		and cover the container */
  background-position: center, center;
  background-size: cover, cover; 

  /* Optional: Fallback 
	background color */
  background-color: #e52e71;
}

Explanation of Properties

- `background-image`: A comma-separated list defines multiple background layers. The first image listed is on top. - `background-repeat`: This property takes a comma-separated list of values that correspond to the layers defined in `background-image`. - `no-repeat` for the `url()` prevents the image from tiling. - `repeat` (the _default value_) for the `radial-gradient` ensures the gradient (or in this case, a single large gradient that fills the space) covers the entire area. If you use the standard `radial-gradient()` function, it automatically sizes to fill the container and doesn't need to "repeat" in the traditional sense, but explicitly setting `repeat` confirms the desired behavior for the browser. - `background-size`: `cover` ensures both the image and the gradient cover the entire element while maintaining their aspect ratios where applicable. [^26][^11][^12][^13][^14]

By using this method, the image appears once, while the gradient naturally spans the full size of the container as a distinct background layer beneath it. [^15][^16]
