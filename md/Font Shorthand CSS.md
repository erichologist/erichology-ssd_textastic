[^1][^2]### Key CSS Font PropertiesThe primary properties used to manage fonts include: [^1][^3][^4][^5][^6]- `font-family`: Specifies the typeface for text. It's best practice to list multiple font names as a "fallback" system (e.g., font-family: Arial, Helvetica, sans-serif;). The browser uses the first font it supports.- `font-size`: Sets the size of the text. Common units include `px` (pixels), `em` (relative to the parent element's font size), and `rem` (relative to the root HTML element's font size), which are useful for responsive design.- `font-weight`: Defines the thickness or boldness of the characters. Values can be keywords like normal and bold, or numeric values from `100` to `900`.- `font-style`: Specifies the style of the font, most commonly normal, italic, or oblique.- `font-variant`: Used to switch between normal and `small-caps` text.- `line-height`: Sets the space between lines of text. The `font` Shorthand PropertyTo simplify your code, you can use the font shorthand property to set multiple properties in a single declaration. The __syntax follows a specific order__: [^7]```lang-css.p {	font:			font-style 			font-variant 			font-weight 			font-size/line-height			font-family;}.p {	font:			italic			bold			16px/1.5			Arial,	sans-serif;}```__font-size__ and __font-family__ are __*required*__ for the shorthand property to work. Other values are optional and will use their default settings if omitted. [^7][^8]###### Using Custom Web FontsBeyond standard web-safe fonts (like Arial, Times New Roman, and Courier New), you can use custom fonts via the `@font-face` rule. This allows you to load font files (commonly WOFF or WOFF2 formats) directly onto your web server. [^9][^10][^11][^12]```lang-css@font-face {  font-family: "MyCustomFont";  src: url("myfont.woff2") 					format("woff2"),       url("myfont.woff") 			 		format("woff");}.custom-text {  font-family: "MyCustomFont", 	  Helvetica, sans-serif;}```Alternatively, services like Google Fonts provide an easy way to include custom fonts in your projects without hosting the files yourself. [^1]:https://www.programiz.com/css/fonts[^2]:https://www.geeksforgeeks.org/css/css-fonts/[^3]:https://www.youtube.com/watch?v=Zj0Z2QAWEWE[^4]:https://www.w3schools.com/css/css_font_style.asp[^5]:https://www.w3schools.com/css/css_font_size.asp[^6]:https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Fonts[^7]:https://www.w3schools.com/css/css_font_shorthand.asp[^8]:https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Text_styling/Fundamentals[^9]:https://www.w3schools.com/css/css3_fonts.asp[^10]:https://penpot.app/blog/embed-custom-fonts-font-face-css/[^11]:https://katex.org/docs/font[^12]:https://frerejones.com/faq
