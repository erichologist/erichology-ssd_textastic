These elements are used to create the interactive parts of a web page.# Form & Input ElementsThese are core to user interaction, allowing data entry and submission.- `<form>`: Defines an HTML form for user input, acting as a container for all input elements.- `<input>`: The most versatile element, with a type attribute that changes its behavior:type="text": A single-line text field.type="password": A single-line text field that masks the input.type="checkbox": A small square that can be checked or unchecked.type="radio": A circular button where only one option can be selected within a group.type="submit": A button that submits the form data.type="file": Allows users to select files for upload.`<button>`: A clickable button, often used for submitting forms, resetting data, or triggering JavaScript actions.`<select>`: Creates a drop-down list of options.`<option>`: Defines an available option within a <select> list.`<textarea>`: A multi-line text input control for longer user messages.`<label>`: Defines a descriptive label for form elements, improving accessibility.`<fieldset>`: Groups related elements within a form visually.## Navigational & Layout ElementsThese elements help structure the page and guide the user through the interface.`<a>`: The anchor element, used to create hyperlinks to other resources or sections of the page.`<nav>`: Defines a section containing navigation links.`<header>`: Defines the introductory or navigational part of a section or document.`<footer>`: Defines the footer for a document or section.`<aside>`: Defines content related to the main content but separate from it, often presented as a sidebar.`<div>`: A generic container used for grouping and styling elements with CSS.`<span>`: An inline container used for applying styles to a small part of text or other inline elements.## Other Interactive & Dynamic Elements`<details>` / `<summary>`: Create a native disclosure widget that the user can open and close to show or hide additional details.`<progress>`: Represents the progress of a task, often displayed as a progress bar.`<dialog>`: Represents a dialog box or other interactive component, such as a pop-up or modal.For a complete reference of HTML elements by category, the W3Schools HTML Element Reference is a valuable resource.```lang-html<meta charset="UTF-8"><div class="Y3BBE" data-sfc-cp="" jsaction="rcuQ6b:&amp;p4kqkf_8|npT2md" jscontroller="zcfIf" jsuid="p4kqkf_8" data-hveid="CAEQAA" data-processed="true"
