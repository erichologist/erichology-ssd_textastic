How to get the weather in a specified area?		- The weather in the sidebar is automatically obtained based on the IP address by default. Modify [[Common tools]] and manually specify `https://i.tianqi.com/?c=code&id=34&bdc=%23&icon=4&site=14&py=chongqing` chongqing and change it to the pinyin of the city you want.		- Home page weather You can also manually specify the region, quickadd macro -home workspace -- click config-fetchhomepage and click the gear icon to set the weather.2. How to change the font?   The main font configured by default in the sample library is [[LXGWWenKai-Light.ttf]] and the code block font is [[JetBrainsMono-Regular.ttf]]. You can install it yourself and it will be automatically recognized.	If you want to install other fonts, open the style settings, 2.2.1 Font settings, and fill in the **font name** in the main font. Note that if the font name has spaces, it needs to be enclosed in single quotes.		The font needs to be installed in the system before it can be called successfully. For example, the **font name** displayed after the win system is installed is the real font name.		![[Pasted image 20220119151051.png]] ^d0e9993. How to change the OB background image?		Open the style settings setting, 1.2.1 work page background, turn on the background, and set the wallpaper path in custom theme light (for light themes) or custom theme dark (for dark themes). The wallpaper path needs to use a similar format url("app://local/XXXXX) to set the local image.		For example, windows image path setting		url(app://local/D:/Documents/XXXX.jpg")		mac system image path setting url("app://local/Users/XXXX.jpg")4. What is the difference between the workspace page background and the note background?		The workspace page background refers to the entire OB interface background, and the note background is only the background of the current md document. The two can be set at the same time if they do not conflict. Of course, the background will be superimposed together. If you only need the entire OB to be a background image, just turn off the note background.5. How to update the songs and daily quotes on the homepage?		Click the topaz picture on the homepage or reload the homepage in the sidebar to get the latest songs and words again. Why is it not displayed after re-acquisition? Just click to refresh the homepage.		![[Pasted image 20220119152758.png]]6. Memos cannot be started and opened?		Enable the core plug-in journal and specify the journal folder location.7. When loading some data on the homepage, the data is not fully displayed?		If the clock doesn't move or the homepage doesn't display in full. Just click to refresh the homepage manually.8. How to implement the sidebar of commonly used tools with buttons?		In fact, it is the `88-template/common tools` note document. After opening it, drag the icon in front of the document title to the sidebar.9. The sample library currently has more than fifty plug-ins, which is too many. If you want to maintain the main functions of the sample library, you will need several plug-ins.		There are not many core plug-ins really required by the sample library. Most of them are auxiliary plug-ins for making Ob more convenient to use, which can be turned on according to your own needs.		If you want to experience the most streamlined version of the sample library, it's easy.		Modify [[FastStart-StartupScript]] ![[Pasted image 20220315145116.png|500]] as shown in the picture to start the minimum sample library running plug-in configuration.		It only takes 100ms to start ob after startup		![[Pasted image 20220315144725.png|300]]10. The sidebar floating memos cannot be opened and there is an error message?			You need to first `ctrl+p` ==>`Open other libraries`, and then select the "20-diary" folder of the sample library. After opening it once, this floating button will automatically take effect. For details, see [[Obsidian library-in-library gameplay#implementation]]11. Why does switching color matching under style setting have no effect?	![[Pasted image 20220429154332.png]]	Pay attention to whether the color settings in 2.1 include custom colors. The custom color settings here have a higher priority. It is recommended to restore all the color settings inside to the default.12. How to cancel the automatic loading of ob's home page? I want to open ob and display the notes from the last time it was closed?	Open quickadd settings, macro management, and turn off the startup loading option of the home workspace.	![[Pasted image 20220523110336.png]]13. How to transplant the animated version of weather to your own homepage? And get the weather for a specified city?    Directly copy the content between the "Text version of weather plus icon" comments, and copy "88-Template/script/dv_weatherSvg.js" to enable the [Weather] weather.css style fragment and the transplantation is successful. To set the weather in a specified area, you need to set it as shown in the quickadd macro home workspace. ![[Pasted image 20220531101243.png|400]]14. How to transplant animated cats to your own homepage?    Like the colorful clock, the animated cat is also generated by react components. You need to install the react_component plug-in first and copy`\88-Template\ReactJS\react_cat.md` so that the animated cat code will take effect.## ❓ FAQ1.
