By default, this cycles through words found within the current document. The specific functionality for SVG elements would depend on whether a dedicated SVG bundle is installed and configured. ### Using Default Word Completion_____To use the default completion feature:- Type the beginning of a word (e.g., `<circ`).- Press the `Escape` key.- TextMate will attempt to complete the word based on other words in your current file (e.g., `<circle`).- If multiple options are available, you can cycle through them by pressing `Escape` repeatedly or cycle backwards using `Shift + Escape`. [^1][^2][^4][^5]### Enhancing Completion with Bundles/Snippets____For more robust, language-specific code completion (like for SVG elements and attributes), you would typically need a TextMate bundle designed for that purpose. - **SVG Bundles**: Existing SVG bundles mentioned in discussion forums are often aged and may not offer full, modern auto-completion.- **Custom Snippets**: A common approach in TextMate is to create custom snippets with tab triggers. You can define a short trigger (e.g., `circ`) that, when followed by the Tab key, expands into a full SVG snippet, such as:```lang-xml<circle cx="${1:0}" cy="${2:0}" r="${3:0}" 	fill="${4:black}" />	<!-- same ↓ -->	<circle cx="${1:0}"	 cy="${2:0}"	 r="${3:0}"	 fill="${4:black}"/>```- **Tab Stops**: The `${1}`, `${2}`, etc., are tab stops that allow you to jump between parameters using the Tab key after insertion.- **Completion Commands**: Bundles can also utilize shell commands to generate a list of completion candidates. This is a more advanced method used in bundles for languages like PHP or Ruby to provide context-aware suggestions (functions, methods, etc.).
