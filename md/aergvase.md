The values are applied in a clockwise order: top, right, bottom, left. [^1][^2][^3][^4]  Shorthand Syntaxes The number of values provided determines how they are applied to the element's sides. [^2]  | Values Specified [^1][^2][^5][^6][^7] | Syntax Example | Application Order  || --- | --- | --- || One value | — | All four sides get 10px of padding (top, right, bottom, and left).  || Two values | — | Top and bottom get 10px; right and left get 20px.  || Three values | — | Top gets 10px; right and left get 20px; bottom gets 30px.  || Four values | — | The values are applied to the top (10px), right (20px), bottom (30px), and left (40px), in that order.  |Example You can use various units for padding values, such as , , , etc., but negative values are not allowed.
