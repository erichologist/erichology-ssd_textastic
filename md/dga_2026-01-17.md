Pure CSS gradient color transitions are complex, so animating position or using pseudo-elements are the standard cross-browser solutions. Method 1: Animating background-positionThis technique creates a subtle, shifting effect where the gradient moves across a large background area. It works well for dark mode aesthetics by using a dark color palette. HTML:```lang-html<div class="animated-background-dark">    <!-- Your website content goes here -->    <h1>Animated Dark Mode Gradient</h1>    <p>The background is subtly shifting.</p></div>```CSS:```lang-cssbody {	margin: 0;	padding: 0;	/*Ensure content is visible over the dark background */    color: white;	font-family: sans-serif;	text-align: center;}.animated-background-dark {	/*Define a large background		with dark colors */    background: linear-gradient(-45deg, #1a1a2e, #16213e, #0f3460, #1f4287);	/*Make the background larger		than the viewport */    background-size: 400% 400%;	height: 100vh;	width: 100vw;	/*Apply the animation */    animation: gradientShift 15s ease infinite;	/*Center content */    display: flex;	flex-direction: column;	justify-content: center;	align-items: center;	position: relative;	overflow: hidden;	/*ensures the moving gradient		doesn't cause scrollbars */}@keyframes gradientShift {	0% {	background-position: 0% 50%;	/*Start at left center */}50% {	background-position: 100% 50%;	/*Move to right center */}100% {	background-position: 0% 50%;	/*Return to start */}}```This method is simple and highly performant. You can experiment with different color stops and angles for different visual effects. Method 2: Animating Opacity for a Morphing/Transition EffectFor a more "morphing" look, where the colors themselves seem to transition smoothly or when transitioning from a light to a dark theme, using pseudo-elements and animating opacity is effective. HTML:```lang-html<div class="morphing-background-container">    <!-- Content goes here -->    <h1>Morphing Gradient</h1></div>```CSS:```lang-css.morphing-background-container {	position: relative;	height: 100vh;	overflow: hidden;	/*Base dark gradient */    background-image: linear-gradient(to bottom right, #0a0a0a, #333333);}.morphing-background-container::before {	content: "";	position: absolute;	inset: 0;/*shortcut for top: 0;		 right: 0;bottom: 0; left: 0; */	/*Alternative gradient to transition to */    background-image: linear-gradient(45deg, #4b0082, #000080);	/*Dark violet and navy */    opacity: 0;/*Initially hidden */	transition: opacity 3s /*Animates smoothly */		 ease-in-out infinite alternate;}.morphing-background-container:hover::before {	opacity: 1; /*Reveals the		second gradient on hover */}/*Optional:add keyframes to cycle automatically */@keyframes morph {	0% {	opacity: 0;}100% {	opacity: 1;}}.morphing-background-container::before {	animation: morph 6s ease-in-out infinite alternate;}```In this example, the ::before pseudo-element with the second gradient smoothly fades in and out over the base gradient, creating a sophisticated morphing effect within a dark color scheme.For more examples and inspiration, you can check out various CSS background effect examples online---Creating a CSS animated morphing gradient background for dark mode is achievable using CSS  to animate the  of a large gradient image, or by animating the  of a dark overlay.
