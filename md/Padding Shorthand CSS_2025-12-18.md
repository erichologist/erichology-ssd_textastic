This gives the content "breathing room" and improves readability and visual hierarchy. [^1][^2]You can apply padding using individual properties for each side or a shorthand property for more compact code. ### **Individual Properties**[^4][^5][^6][^7][^8]You can control the padding for each side of an element individually:  - `padding-top`: Sets the top padding. - `padding-right`: Sets the right padding. - `padding-bottom`: Sets the bottom padding. - `padding-left`: Sets the left padding.*example:*```lang-css.element {  padding-top: 10px;  padding-right: 20px;  padding-bottom: 10px;  padding-left: 20px;}```#### ***Shorthand Property***[^8][^11][^12][^13][^14]The `padding` shorthand property allows you to define padding for multiple sides in a single declaration. The values are applied in a clockwise order: *top, right, bottom, left*. >###### *One* value>>   **all sides**>###### **Two** values>>   **vertical** | **horizontal**>###### ***Three*** values>>   **top** | ***horizontal*** | **bottom**>###### **Four** values>>   **top** | **right** | *bottom* | **left****One value** (**all sides**):```lang-css.element {  padding: 10px;	 /* 10px on all four sides */}```**Two values** (**vertical** | **horizontal**):```lang-css.element {  padding: 10px 20px;	 /* 10px top/bottom,	  20px left/right */}```**Three values** (**top** | **horizontal** | **bottom**):```lang-css.element {  padding: 10px 20px 30px;	  /* 10px top, 20px left/right,	  30px bottom */}```**Four values** (**top** | **right** | **bottom** | **left**):```lang-css.element {  padding: 10px 20px 30px 40px;	 /* Clockwise: 10px top, 20px right,	 30px bottom, 40px left */}```### **Key Considerations****Units**:Padding values can be in pixels (`px`), percentages (`%`), ems (`em`), or other length units.**Negative Values**:Negative values are not allowed for padding, unlike margins.**Box Model**:By default (`box-sizing: content-box`), adding padding increases the total width and height of an element. To make the element's specified width and height include the padding and border, use box-sizing: border-box.**Logical Properties**:For internationalization, CSS provides logical properties like padding-block (vertical space) and padding-inline (horizontal space) that adapt based on the writing mode of the document.
