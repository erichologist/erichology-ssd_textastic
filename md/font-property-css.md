The font-size and font-family values are required. If one of the other values is missing, their default value are used.2. If defined, font-style, font-variant, font-weight must precede font-size.3. If defined line-height must immediately follow font-size preceded by "/", like this: 15px/30px.4. font-family must be the last value specified.⠀[Show demo ❯](https://www.w3schools.com/cssref/playdemo.php?filename=playcss_font) |  Default value: |  *The default value of the font properties* |  | --- | --- ||  Inherited: |  yes ||  Animatable: |  yes, *see individual properties*.
