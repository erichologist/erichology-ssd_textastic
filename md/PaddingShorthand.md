The values are assigned in a ***clockwise*** order starting from the top: **top**, **right**, **bottom**, **left**. | ---: | :---: | :---- ||  →   |  top  |   ↓   || left |       | right ||  ↑   | bottom|   ←   || ---: | :---: | :---- || ┏━━  |        |  ━━┓ || ┃ →  |  top   |  ↓ ┃ ||      |        |      || left |        | right||  ↑   |        |   ←  || ┃    |        |    ┃ || ┗━━  | bottom |  ━━┛ |```lang-sh┏━━━━━━━━━━━━━━━━━━━━┓┃                   ┃┃                   ┃┃                   ┃┃                   ┃┃                   ┃┃                   ┃┗━━━━━━━━━━━━━━━━━━━┛```## Syntax and UsageThe syntax varies depending on the number of values provided:One value (`padding: A;`): Applies the same padding A to all four sides (**top**, **right**, **bottom**, and **left**).   - Example: `padding: 10px;` results in 10px padding on all sides.```lang-csspadding: 10px;/* Equivalent to:	padding-top: 10px;	padding-right: 10px;	padding-bottom: 10px;	padding-left: 10px; */```Two values (`padding: A B`;): The first value A sets the top and bottom padding, and the second value B sets the right and left padding.   - Example: `padding: 10px 20px;` results in 10px padding on top and bottom, and 20px padding on the right and left.```lang-csspadding: 10px 20px;/* Equivalent to:	padding-top: 10px;	padding-bottom: 10px;	padding-right: 20px;	padding-left: 20px; */```Three values (`padding: A B C;`): The first value A sets the top padding, the second value B sets the right and left padding, and the third value C sets the bottom padding.   - Example: `padding: 10px 20px 30px;` results in 10px top, 20px right and left, and 30px bottom padding.```lang-csspadding: 10px 20px 30px;/* Equivalent to:	padding-top: 10px;	padding-right: 20px;	padding-bottom: 30px;	padding-left: 20px; */```Four values (`padding: A B C D;`): The values apply to the sides individually in clockwise order: top (**A**), right (**B**), bottom (**C**), and left (**D**).   - Example: `padding: 10px 20px 30px 40px;` results in 10px top, 20px right, 30px bottom, and 40px left padding.[^2][^3][^5][^6][^7][^8] ```lang-csspadding: 10px 20px 30px 40px;/* Equivalent to:	padding-top: 10px;	padding-right: 20px;	padding-bottom: 30px;	padding-left: 40px; */```You can use various units like pixels (`px`), percentages (`%`), or em units for the values, ***but negative values are not allowed***. For more details and examples, refer to the MDN Web Docs on the padding shorthand property or W3Schools CSS Padding guide. [^2]| Values Specified [^1][^2][^5][^6][^7] | Syntax Example | Application Order  || :--- | :--- | :--- || One value | `padding: 10px;` | All four sides get 10px of padding (top, right, bottom, and left).  || Two values | `padding: 10px 20px;` | Top and bottom get 10px; right and left get 20px.  || Three values | `padding: 10px 20px 30px;` | Top gets 10px; right and left get 20px; bottom gets 30px.  || Four values | `padding: 10px 20px 30px 40px;` | The values are applied to the top (10px), right (20px), bottom (30px), and left (40px), in that order.  |### Example ```lang-css/* This is equivalent to:  padding-top: 25px;  padding-right: 50px;  padding-bottom: 25px;  padding-left: 50px; */p.demo {    padding: 25px 50px;    border: 1px solid black;}```You can use various units for padding values, such as `px`, `em`, `%`, etc., but negative values are not allowed.
