Using this technique, the size of your font will directly translate to the size of the icon. For example, if you set your font-size in CSS to be 16px, you will get a 16px icon. This method was first introduced by IcoMoon.![screenshot of font metrics](https://icomoon.io/images/old/font-metrics-082034acded993e15d0b508caef9ee25.png?vsn=d)<center><sup>screenshot of font metrics</sup></center>Using this alignment technique, the bottom of the icon will be placed near the baseline of any text before/after the icon. This is normally the expected behavior but you can always change the baseline of your font via the preferences panel in the Font tab.![screenshot showing how to change the baseline](https://icomoon.io/images/old/baseline-83331e391fc2e24e1e15ece0a2dc4f0d.png?vsn=d)<center><sup>screenshot showing how to change the baseline</sup></center>Pro Tip: By changing the baseline, you can change how your icons align vertically.Pro Tip: The Whitespace Width option determines the width of the whitespace character (0x20) as a percentage of the height of the em square. Using a larger number would make the space character take up more space horizontally.```lang-html<script type="text/javascript" src="../assets/tex-svg.js"></script><script type="text/javascript" src="../assets/mathin.js"></script><script type="text/javascript" src="../assets/mathsvg.js"></script><script type="text/javascript" src="../assets/tex-chtml.js"></script><script defer src="https://cdn.jsdelivr.net/npm/mathjax@4/tex-chtml.js"></script><script>MathJax = { tex: { autoload: { color: [], colorv2: ['color']}}};</script>```____The precise value is 14.28571428571429% > (100% * 256 / 1792).Also, Font Awesome's 4 font has been moved to [here](https://raw.githubusercontent.com/FortAwesome/Font-Awesome/fa-4/fonts/fontawesome-webfont.svg)
