Standard Markdown does not natively support adding custom classes or attributes to elements. However, many Markdown processors and extensions (such as kramdown, Maruku, or those used in platforms like Hugo and Obsidian) offer extended syntax to achieve this. ## 1. The Concept of Attribute Selectors (CSS)Attribute selectors in CSS allow you to target HTML elements based on the presence or value of a specific attribute. | Selector         | Meaning&nbsp;& Examples    || :--------------- | -------------------------- || `[attr]`         |selects all elements with the specified attribute.   || ^ex`[data-role]`    |selects any element with the `data-role` attribute.  || `[attr="value"]` |selects elements where the attribute value is an exact match.|| ^ex`a[href="#"]`    |selects anchor tags where the href is exactly `"#"`. ||`[attr~="value"]` |selects elements where the attribute value is a space-separated list containing a specific word. || ^ex`img[alt~="art"]`|selects images with the word "art" in their alt text.||`[attr^="value"]` |selects elements where the attribute value starts with a specific value.|| ^ex `li[class^="a"]` |selects list items where the class starts with "a". ||`[attr$="value"]` |selects elements where the attribute value ends with a specific value.  || ^ex`li[class$="a"]`  |selects list items where the class ends with `"a"`. ||`[attr*="value"]` |selects elements where the attribute value contains a specific value anywhere in the string. || ^ex`li[class*="a"]`  |selects list items where the class contains `"a"`. ||                  | [^2][^6][^7][^8][^9]                               |For a live demo of CSS attribute selectors, you can explore this [CodePen](https://codepen.io/team/css-tricks/pen/OPobRY) example. ## 2. The Demo in an Extended Markdown EnvironmentIn an environment that supports Markdown attributes (like Hugo or Obsidian with the right plugins), you can assign attributes to a Markdown element, which then allows CSS attribute selectors to target it. Markdown Input (using an extended syntax)This syntax typically involves placing the attributes in braces {} immediately following the element. markdown### A Header with an ID {: #section-id}This is a paragraph with a custom attribute. {data-info="demo-text"}* List item one* List item two {: #class="highlight"}  {: #highlight}* List item three### Corresponding HTML OutputWhen processed, the Markdown above would generate HTML similar to this:```lang-html<h3 id="section-id">A Header with an ID</h3><p data-info="demo-text">This is a paragraph with a custom attribute.</p><ul><li>List item one</li><li class="highlight">List item two</li><li>List item three</li></ul>```Applying a CSS Attribute SelectorYou can then use CSS to style these elements using attribute selectors. ```lang-css/* Styles the paragraph with the specific data-info attribute */p[data-info="demo-text"] {  color: blue;  font-style: italic;}/* Styles any element that has an ID starting with 'section-' */[id^="section-"] {  border-bottom: 2px solid red;}/* Styles any list item with the class attribute containing "highlight" */li[class~="highlight"] {  background-color: yellow;  padding: 5px;}h1[id*="1."],h2[id*="2."],h3[id*="3."],h4[id*="4."],h5[id*="5."],h6[id*="6."] {  background-color: #FE06;  padding: 5px;}```Attribute selectors are a feature of CSS, not Markdown itself.
