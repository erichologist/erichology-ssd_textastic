Creating an animated gradient background for dark mode is a great way to add a modern, dynamic feel to a website. The standard technique involves defining a large background-size and then animating the background-position using CSS @keyframes. Here is a full example:HTML```lang-html<div class="animated-dark-gradient">  <h1>Animated Gradient Dark Mode</h1>  <p>This background shifts smoothly between dark, complementary colors.</p></div>```CSS```lang-cssbody {	margin: 0;	padding: 0;	/*Ensure the body is dark	behind the main container	if needed */  background-color: #000;}.animated-dark-gradient {	/*Dark Mode Colors: Use deep,	rich colors that contrast	well with white text */  background: linear-gradient(    -45deg,    #1a1a2e, /*Deep space sparkle */    #16213e, /*Midnight blue */    #0f3460, /*Indigo */    #53d8fb  /*A pop of light blue for dynamism */  );	/*Required for animation:	Make the background significantly	larger than the container */  background-size: 400% 400%;	/*Apply the animation */  animation: gradientAnimation 15s ease infinite;	/*15s duration,	smooth ease, loops forever */    /*Sizing and layout for	the example content */  height: 100vh;	display: flex;	flex-direction: column;	justify-content: center;	align-items: center;	color: white;/*White text	for dark mode readability */	text-align: center;	padding: 20px;	box-sizing: border-box;}/*Define the animation movement */@keyframes gradientAnimation {	0% {	background-position: 0% 50%;}50% {/*  Moves the background position		to the right/bottom halfway		through the animation */    background-position: 100% 50%;}100% {	/*Returns to the start position */    background-position: 0% 50%;}}```Key ConceptsDark Mode Color Palette: The gradient uses deep, unsaturated colors (#1a1a2e, #16213e) with one brighter accent (#53d8fb) to maintain a dark theme while still providing visual interest.background-size: 400% 400%: This is crucial. It stretches the linear gradient to four times the width and height of its container, allowing for significant movement across the colors.@keyframes: This rule defines the start, middle, and end points of the animation. By changing background-position from 0% 50% to 100% 50% and back, the visible portion of the large gradient shifts smoothly left and right.animation: ... infinite;	: This property applies the keyframes to the element, making it loop indefinitely. You can view a live version of a similar effect on CodePen. ---Creating an animated gradient background for dark mode is a great way to add a modern, dynamic feel to a website.
