The property used to manage this feature explicitly is font-feature-settings.[^31][^32]Contextual alternates are alternative glyph designs that a font automatically uses based on the surrounding characters (the context). They are designed by the font creator to improve readability and ensure that characters connect properly in scripts, creating a more natural and continuous flow, similar to handwriting.[^31][^23][^24]## CSS UsageThe primary way to control contextual alternates in CSS is using the `font-feature-settings` property: ```lang-css/* Enables contextual alternates (this is usually the default) */.element {  font-feature-settings: "calt" on;}/* Disables contextual alternates */.element-no-calt {  font-feature-settings: "calt" off;}```You can find more examples and explore other OpenType features on the CSS-Tricks `font-feature-settings` almanac. A more modern, lower-level CSS property is font-variant-alternates, but it generally requires the use of the `@font-feature-values` at-rule to define human-readable names for specific font indexes, making `font-feature-settings` the more common approach for direct OpenType tag control.[^26][^27][^28][^29]## Key PointsAutomatic by Default: The `calt` feature is usually on by default in web browsers and design software because it is essential for proper rendering and appearance in many typefaces, especially connected scripts.Problem Solvers: They address visual issues like character collisions or awkward spacing by swapping out standard glyphs for better-fitting alternatives.Distinction from Ligatures: While they serve a similar purpose to ligatures, contextual alternates change only one glyph at a time based on context, whereas ligatures replace two or more characters with a single combined glyph[^31]In CSS, contextual alternates are controlled using the OpenType feature tag , which is enabled by default in most modern browsers.
