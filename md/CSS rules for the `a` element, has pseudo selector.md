The :has() pseudo-class (often called the "parent selector") can select elements based on their contents, but it has specific limitations:- Pseudo-elements are not valid within `:has():` The `::after` pseudo-element (which requires a double colon in modern CSS, but a single colon is often accepted for backward compatibility) is a pseudo-element. You cannot use :has() to query the existence of a pseudo-element child.- `:has()` cannot be nested within a pseudo-element: You cannot apply `:has()` to a `::after` pseudo-element itself. [^1][^4][^5][^6]> The intended use might have been to select an a element that has a sup element as a direct child, to which a style is applied after the content of the `a` element.### Correct Syntax ExamplesIf you intended to select an anchor (`<a>`) element that contains a superscript (`<sup>`) and apply a style to the anchor itself, you would use	```lang-cssa:has(> sup)::after {  content: " *";  /* Other CSS rules for the generated content */}```You could then use a separate rule to define the `::after` content of that specific anchor:[^7]```lang-cssa:has(> sup)::after {  content: " *";  /* Other CSS rules for the generated content */}```______`a.classer:after:has(>sup)`If you intended to select the content after the sup element inside an `a` element, you would not use `:has()` at all, but a direct or sibling selector depending on the specific structure. Pseudo-elements like `::after` and `::before` cannot have their own classes. [^10]  ## Breakdown of the Invalid Selector ### The intended structure attempts to combine several concepts in an impermissible order: - `a.classer`: Selects an anchor (`<a>`) element with the class `classer`. - `:after (or ::after)`: This is a pseudo-element used to insert content after the selected element's content. It is part of the element's rendering but is not a real DOM node that can have classes. - `:has(>sup)`: This is a powerful new *pseudo-class* (often called the "parent selector") that selects an element if any of the relative selectors passed as an argument match at least one element when anchored against it. [^10][^11][^12][^13][^14]The CSS specification does not allow a class selector to follow a pseudo-element because pseudo-elements themselves don't have classes. [^10]  ### A Valid Alternative If your goal is to select an anchor element with a specific class that contains a `<sup>` element and apply styling to that anchor's generated content, you can modify the selector to place the `:has()` pseudo-class correctly:```lang-css/* Selects an anchor element with class "classer" that contains a sup element,    and applies styles to the ::after content of that anchor element */a.classer:has(>sup)::after {  /* your styles here */  content: " ▼"; /* Example: add a dropdown indicator */  /* ...other styles */}```This is a valid use of the `:has()` selector, as it correctly uses the pseudo-class to select the parent element (a.classer) based on its child (sup), and then applies the `::after` pseudo-element to the *parent*.
