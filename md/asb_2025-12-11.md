typographic styles for fonts, enabling effects like small caps, different numeral styles (lining, old-style, tabular), fractions, and ligatures, giving fine-grained control over web typography beyond basic size and weight. It leverages OpenType features in fonts to add stylistic flair, improving readability and design, though support varies by font and browser.[^11][^12][^13][^14][^15]  ### Key font-variant Properties- • `font-variant-caps`    :Controls capital letter styles.        - `small-caps`            :Converts lowercase to smaller uppercase letters.        - `petite-caps`, `all-petite-caps`, `titling-caps`            :Other cap styles.- • `font-variant-numeric`    :Manages number and fraction appearance.        - `tabular-nums`            :Fixed-width numbers *for alignment in tables/charts*.        - `oldstyle-nums`            :Numbers with varying heights (like old books).        - `stacked-fractions, diagonal-fractions`            :Different fraction styles.        - `slashed-zero`            :Adds a slash to the digit '0'.- • `font-variant-ligatures`    :Controls special letter combinations.        - `common-ligatures` (fi, fl), `discretionary-ligatures`, `contextual-alternates`.- • `font-variant-position`    :Handles superscript/subscript.[^12][^13][^15][^16][^17][^18][^19][^20][^21][^10]        - `superscript`, `subscript`            :(often handled by `<sup>`/`<sub>` tags, but can be controlled here).### How It Works- Shorthand:`font-variant` acts as a shortcut to set multiple specific variant properties at once (e.g., `font-variant: small-caps tabular-nums;`).- OpenType Features[^10]:These properties map to advanced features built into modern fonts, allowing browsers to access stylistic alternates like ligatures or specific numeral sets.[^11][^12][^13]Example Usage (CSS)```lang-cssp {  font-variant: small-caps;	 /* All lowercase becomes small caps */}.tabular-data {  font-variant-numeric: tabular-nums;	 /* Numbers align in columns */}.fancy-text {  font-variant-ligatures: discretionary-ligatures;	 /* More elaborate ligatures */}```____ in CSS is a powerful shorthand property and a set of individual properties (like , ) that control alternate glyphs and typographic styles for fonts, enabling effects like small caps, different numeral styles (lining, old-style, tabular), fractions, and ligatures, giving fine-grained control over web typography beyond basic size and weight.
