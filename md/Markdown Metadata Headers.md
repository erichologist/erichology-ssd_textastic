This metadata is usually written in YAML format, enclosed by triple-dashed lines (---). Here are some common frontmatter options and their uses: ### Standard Metadata: • `title`:The title of the page or post. This is often used in &lt;title&gt; tags, headings, or navigation menus. • `description`:A brief summary of the content, used for SEO metadata (e.g., &lt;meta name="description"&gt;) and potentially in content listings. • `date`:The publication or creation date of the content. • `author`:The author(s) of the content. • `tags`:A list of keywords or categories associated with the content, used for organization and filtering. • `categories`:Similar to tags, but often used for broader categorization. • `slug`:A URL-friendly identifier for the page, often overriding the default generated from the title. • `published`:A boolean flag (e.g., true or false) indicating whether the content should be publicly visible. ### Layout and Rendering Options: • `layout`:Specifies a template or layout file to be used for rendering the content. This is common in static site generators like Jekyll or Hugo. • `head`:Allows injecting custom HTML or metadata into the &lt;head&gt; section of the generated page, such as custom styles or additional meta tags. • `navbar`:Controls the visibility or behavior of a navigation bar on the page. • `tableOfContents`:Configures the generation and display of a table of contents, including heading levels to include or whether to hide it entirely. • `lastUpdated`:A boolean flag to display or hide the last updated timestamp on the page. • `editLink`:A boolean flag to display or hide a link to edit the source of the page. ### Custom VariablesBeyond these common options, you can define any custom variables within the frontmatter that your specific static site generator, CMS, or processing tool can utilize. These can be simple key-value pairs, arrays, or even more complex data structures. ### Example Frontmatter:```language-yaml---title: "My Awesome Blog Post"description: "A comprehensive guide to Markdown frontmatter options."date: 2025-11-25author: "AI Assistant"tags:  - markdown  - frontmatter  - documentationlayout: "post"published: true---```A Markdown metadata header, often referred to as a "front matter" or "YAML front matter," is a block of key-value pairs at the beginning of a Markdown document, used to provide structured information about the document itself. This metadata is typically not rendered as part of the main content but is instead used by Markdown processors, static site generators (like Jekyll, Hugo, or MkDocs), or other tools to manage, organize, and display content. ### Here's how it generally works:Format: The most common format for Markdown metadata headers is YAML (YAML Ain't Markup Language), enclosed within triple-dashed lines (---). Some systems might also support TOML or JSON. Location: The metadata header must be at the very top of the Markdown file, followed by the main content of the document. Key-Value Pairs: Inside the metadata block, you define key-value pairs. The key identifies the type of information (e.g., title, author, date, tags), and the value provides the specific data. ```language-yaml---title: "My Awesome Blog Post"author: "Jane Doe"date: "2025-11-20"tags:  - markdown  - metadata  - tutorialcategories:  - Technology---```#### Purpose:    - **Document Information**: Provides details like title, author, publication date, and description.    - **Categorization and Tagging**: Enables organization of content through categories and tags, facilitating navigation and search.    - **Configuration**: Can include settings for how the document should be processed or rendered (e.g., layout templates in static site generators).    - **External Tool Integration**: Allows for custom metadata that can be used by specific tools or scripts. **Document Information**:Provides details like title, author, publication date, and description.**Categorization and Tagging**:Enables organization of content through categories and tags, facilitating navigation and search. **Configuration**:Can include settings for how the document should be processed or rendered (e.g., layout templates in static site generators).**External Tool Integration**:Allows for custom metadata that can be used by specific tools or scripts. **Rendering**:Markdown processors typically strip the metadata header before rendering the document's content, ensuring that this information is used for processing rather than being displayed directly within the main body of the text.# ABC## DEF### GHI#### JKL##### MNO###### PQR1. one2. three3. two
