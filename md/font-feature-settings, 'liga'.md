It is typically used with `1` (on) or `0` (off), though it is often on by default. Use `font-feature-settings: 'liga' 0;` to disable them. [^1][^2][^3][^4][^5]## Key DetailsPurpose: Activates "standard" ligatures designed by the font creator.Syntax: `font-feature-settings: 'liga' 1;` (enabled) or font-`feature-settings: 'liga' 0;` (disabled).Contextual Ligatures: Often used alongside `'clig'` to enable contextual ligatures.Usage: Best for improving the readability and aesthetic of specific letter pairs, particularly in serif fonts.Caveat: It is a low-level, specific property, often overridden by font-variant-ligatures. [^1][^2][^3][^6][^7]This property is part of the CSS Fonts Module Level 3/4 specification, aimed at granular control over OpenType features.
