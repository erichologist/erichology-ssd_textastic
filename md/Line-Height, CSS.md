It affects readability and layout more than people expect.### Basic syntax```cssp {  line-height: 1.5;}```### Common ways to set it**1. Unitless (recommended)**```css{line-height: 1.5;}```This means *1.5 × the font size*.If font-size is 16px → line height becomes 24px.✔ Best practice because it scales naturally with nested elements.___**2. Length value**```css{	line-height: 24px;	line-height: 1.2rem;}```Fixed spacing regardless of font scaling.___**3. Percentage**```css{line-height: 150%;}```Relative to font size, similar to unitless but less flexible.___### Practical guidelines* Body text: `1.4 – 1.7` → easier reading* Headings: `1.1 – 1.3` → tighter look* UI labels/buttons: `1 – 1.2`Example:```cssbody {  font-size: 16px;  line-height: 1.6;}h1 {  line-height: 1.2;}```### Vertical centering trickFor single-line text:```cssdiv {  height: 50px;  line-height: 50px;}```This centers text vertically inside the box.___If you want, tell me what you're trying to achieve (readability, vertical centering, spacing in a layout, etc.) and I’ll tailor the example.
