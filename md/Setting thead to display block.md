This method is typically used to create a fixed header with a scrollable body, which usually requires setting fixed widths for all columns to ensure they match up. [^1][^2][^3]### How to use display: block for a scrollable table bodyThe primary use case for setting `thead` and `tbody` to `display: block` is to enable vertical scrolling for the body content while keeping the header fixed in place. [^4]Here's the general CSS approach:```lang-csstable, thead, tbody {    display: block;    width: 100%; 		/*optional, to make them span full width*/}tbody {    height: 100px;		/*set a fixed height for the scrollable area */    overflow-y: auto; 		/*adds a vertical scrollbar when content exceeds height */    overflow-x: hidden; 		/*hides horizontal overflow*/}/*Ensure all th and td elements have matching, fixed widths*/th, td {    width: 100px;		/*adjust width as needed for your content */    /*other styling like padding, border etc.*/}````display: block` on `table`, `thead`, `tbody`:This forces them out of their default table rendering behavior.`height` and `overflow-x: auto` on `tbody`:This combination creates the scrollable area.Fixed `width` on `th` and `td`:This is the crucial step to maintain column alignment, as the browser's automatic table layout is no longer in effect. [^2][^3][^5][^6][^7]### Alternative: Use a Wrapper Container [^8]A more modern and often more reliable approach is to wrap the entire `<table>` in a `<div>` container and apply the scrolling properties to that container. The header will scroll with the table, but this avoids breaking the inherent table layout mechanisms and column alignment issues. [^9][^10][^11][^12][^13]```lang-css.table-container {    height: 200px;		/*Set desired height */    overflow-y: auto;		/* Enable vertical scrolling */    /*optional: overflow-x: auto; if horizontal scrolling is also needed*/}table {    width: 100%;		/*Table will stretch to fill its container*/    /*default table display properties are maintained*/}```For more advanced solutions involving sticky headers that remain in view while the body scrolls, a JavaScript-based solution is often necessary for full cross-browser compatibility, although modern CSS `position: sticky` is also an option in newer browsers.
