What’s Inside Your Font File?

How many characters does this font include? Who designed it?
Which version is it? What about the copyright?
FontDrop! reads and shows what’s in your font file.

Simply drag and drop your OpenType or TrueType font files onto this website to see what’s inside them. Supported formats are OTF, TTF, WOFF and WOFF2 files. The result is generated in your browser, no server-side actions needed.

Features

  • Name, style, version and copyright information of the font, if available
  • Shows all glyphs in the font file
  • Shows details for every glyph
  • Detect and show OpenType features*
  • Detect and show ligatures
  • Detect and show language support of font**
  • Shows table data of the font file***
  • Preview of the font with text and waterfall lines
  • Type yourself – test and type with the font
  • Supports variable fonts

There is a subpage of FontDrop! which can compare two fonts with each other, a subpage for language detection, a Vertical Metrics Report, a Advance Width Report and a subpage for searching glyphs.

Find an article about FontDrop! on Medium and check the Fun With Fonts adventure.

Behind the scenes

FontDrop! is a easy-to-use web application. It parses font files with the help of opentype.js library. For variable fonts we use in addition variableFonts.js. The application itself is build with Ember JS and Foundation. The project is realized by Viktor Nübel and Clemens Nübel. UI-Font: FF Attribute. Current example font: Rethink.

For any questions or comments about this site get in touch!

Like FontDrop? Consider supporting the maintenance and development with a small donation!

* FontDrop! detects all features in a font file, also unknown or custom features. Every feature gets an on/off-switch, even if it sometimes will have no visible effect or is useless, e.g. for ‘Required’ features. FontDrop will show all Ligatures in a font file and trys to show all substitute letters. Some features (lookups) are too compelx to show, and sometimes there are substitutes of substitutes, which FontDrop also cannot show.

** FontDrop! compares all Unicode encoded characters in the font file with a own database of languages. For more information about the language detection and a more detailed language report go to FontDrop! Language Report.

*** The following font tables get parsed by opentype.js: name, head, hhea, maxp, os/2, post, cmap, fvar, meta, GSUB and kern. If you want to learn more about all tables that might be used in font files, have a look in the OpenType specs here.
